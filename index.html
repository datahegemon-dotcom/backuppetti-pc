How to set it up

  1. Download the file using the green button above.
  2. Open the downloaded file (look in your Downloads folder).
  3. Windows may show a blue box saying “Windows protected your PC.” This is normal for new apps — your file is safe.
    🛡️ Windows protected your PC
    Click More info, then click Run anyway
  4. BackupPetti starts quietly in the background — no window opens, that's normal. It adds a “BackupPetti” icon to your Desktop and Start Menu: open it to bring up the setup page (or go to http://localhost:8088), then do the three steps below. 👇

Or set it up by hand

  1. Download the file using the green button above (it lands in your Downloads folder).
  2. Open a Terminal and go to that folder: cd ~/Downloads
  3. Make the file runnable (Linux needs this once): chmod +x backuppetti-agent-linux-amd64
  4. Start it: ./backuppetti-agent-linux-amd64
  5. Open http://localhost:8088 in your browser and do the three steps below. 👇
💡 Your USB drive is usually at a path like /media/you/USB. If it isn't in the drive list on the setup page, just type that path in Step 1.

Or set it up by hand

  1. Download the file for your Mac using a button above (it lands in Downloads).
  2. Open Terminal (Applications → Utilities → Terminal) and go to that folder: cd ~/Downloads
  3. Make the file runnable (do this once): chmod +x backuppetti-agent-macos-*
  4. Let macOS trust it (it's a new app, so macOS blocks it by default): xattr -d com.apple.quarantine backuppetti-agent-macos-*
  5. Start it — Apple Silicon: ./backuppetti-agent-macos-arm64 …or Intel: ./backuppetti-agent-macos-amd64
  6. Open http://localhost:8088 in your browser and do the three steps below. 👇
💡 On a Mac your USB drive is usually at /Volumes/YourDriveName. If it isn't in the drive list, type that path in Step 1.

The setup page — 3 quick steps

This part is the same on every system, once the setup page is open at http://localhost:8088.
  1. Choose your drive. Under “Step 1”, pick the drive where files should be saved — usually your USB drive or external disk. If you don't see it in the list, just type its path and click “Use this path” (e.g. D:\ on Windows, /media/you/USB on Linux, /Volumes/USB on Mac).
  2. Open or create a folder — one for each person or account (like “Amma” or “Shop”). Type a name and click “Create folder & open it”, or click an existing folder to open it.
  3. Inside that folder, click the big “Generate QR code for this folder” button. The QR appears right there.
  4. On your phone, open BackupPetti → Your Box → “Scan your box's QR” and point the camera at that QR. Connected! ✅
  5. Want to add another person? Just make another folder and its own QR — each folder keeps that person's files separate.
Want to remove BackupPetti?
🪟 Windows
Open BackupPetti from the Start Menu (or the desktop icon) to bring up the setup page, scroll to the bottom, and click “🗑 Uninstall BackupPetti”. It turns off auto-start, removes the shortcut, and forgets your paired phones — then opens the folder with the app file so you can delete that last file.
🐧 Linux
Open a Terminal and paste:
curl -fsSL https://datahegemon-dotcom.github.io/backuppetti-pc/uninstall-linux.sh | sudo bash
🍎 Mac
Open Terminal and paste:
curl -fsSL https://datahegemon-dotcom.github.io/backuppetti-pc/uninstall-mac.sh | bash
✅ Your backed-up files are never deleted by uninstalling. Removing BackupPetti only clears the app, its startup entry, and which phones were paired — the photos and files already saved on your drive stay exactly where they are.
🔒 Your files go straight from your phone to this computer over your own WiFi — they never leave your house or touch anyone's cloud.
📶 Your phone and this computer must be on the same WiFi (home or shop). That's what keeps everything off the internet.
💻 Keep this running (and the computer switched on) when you back up.
